# Scope of conditional-model work measurements

`conditional_model_work.csv` records actual fitted tree counts, training row-round exposures, original classifier fit times and process high-water RSS. Fit times exclude some surrounding preprocessing, source verification and reporting. RSS is a process maximum, not an isolated model's incremental memory. Neither measure is an end-to-end deployment benchmark.

`conditional_inference_work.csv` reconstructs per-method prediction exposure: every application receives its global200 score and eligible members additionally receive their local model's score, using actual fitted rounds. Pure and blended strategies share those vectors. Summing across the four partition/weighting methods counts each method's logical global exposure; a global source shared between partitions can physically be computed once. Saved-inference audits also repeat prediction calls. Thus the frozen report's phrase "actual prediction row-rounds across the declared conditional methods" denotes logical exposure from fitted model sizes and actual membership counts, not measured processor work or a count of physical prediction calls. It must not be interpreted as end-to-end runtime or charged separately to each blend.

Global400 changes nominal round capacity only. It does not equalize total stored trees, histogram-building costs, serialization size, audit overhead, runtime or memory with a collection of local models. Conditional training changes both the populations and total model capacity; these controls do not identify a pure causal effect of partitioning.
