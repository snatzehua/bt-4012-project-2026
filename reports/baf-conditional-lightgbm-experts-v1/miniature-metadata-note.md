# Original miniature getter metadata

The frozen sixteen-fit miniature completed without warnings and verified original-global versus explicit-weight prediction equivalence, persistence and deterministic repeats. Its independent audit then detected one post-inspection metadata defect in `original200_balanced`.

The production gate creates a shallow copy of that fitted classifier and calls `set_params(class_weight=None)` on the copy to inspect the common booster recipe. LightGBM 4.7.0 shares `_other_params` in a shallow copy. Its getter merges that dictionary over estimator attributes, so the original model's post-inspection `get_params()` and saved `requested_model_params` show `None` for this field. The original object's `class_weight` and retained fitted `_class_weight` both remain `balanced`.

Inspection of the pinned installed implementation establishes that fitting applies weights from `_class_weight`, while the native booster parameter dictionary removes `class_weight`. The saved original balanced predictions match the separately fitted explicit whole-training-weight model at absolute tolerance 1e-12, relative tolerance zero. The supplemental audit checks both retained fit attributes, every other parameter, the native booster, raw membership/costs, persistence, and exact repeats. A zero-fit probe independently reproduces the shallow-copy getter mutation. The raw record, original gate/source identity and first failed assertion are retained; no numerical recipe, fit, score or frozen source was changed.

`miniature-parameter-metadata-correction.json` contains the original requested recipe, raw getter, retained fit state and pinned-library source hash. `production-gates-verification.json` links that correction and checks all sixteen actual saved miniature models. This getter-only defect is confined to the original balanced miniature inspection. Full-data conditional/global400 fits set `class_weight=None` directly, pass explicit whole-training weights, and do not execute the shallow-copy path. Exact source-reference models come from their independently audited historical artifacts, not from miniature models.

The initial independent audit failed before any full-data fit. The corrected independent audit fits no additional model. A future code change can replace this inspection with an isolated copy; the present run preserves its frozen producer and records the metadata distinction transparently.
